🧬 GAUSE — Interactive Explainer

Generalist-averse Affinity Update for Specialist Emergence · niche partitioning without explicit coordination
Core thesis. Under bounded per-agent capacity and non-stationarity, retention of dormant-regime knowledge tracks a single property: whether capacity assignment is independent of current task reward. Competition is the most parsimonious route to a reward-independent assignment — no gate to train, no diversity objective to tune. The assignment is simply the equilibrium the dynamics converge to.

Algorithm The full GAUSE loop in pseudocode ›

GAUSE is a population of bandit learners under competitive exclusion. One step:

# State per learner i: # α_i ∈ Δᴿ niche affinity (a distribution over R regimes) # B_i[r][m] Beta(a,b) belief that method m is good in regime r for each step t: r ← Stream(t) # environment emits the live regime for each learner i: # 1. propose (Thompson sampling) m_i ← argmaxₘ sample Beta(B_i[r][m]) # (ε-greedy exploration, ε decays) raw_i ← q(m_i, r) # reward: high iff m_i is r's best method bonus_i ← +λ·α_i[r] if primary(α_i)=r # 2. generalist-averse niche bonus −0.3·λ·(1−α_i[r]) otherwise adj_i ← raw_i + bonus_i w ← argmaxᵢ adj_i # 3. winner-take-all B_w[r][m_w].a += 1 # 4a. winner reinforces its method belief α_w[r] ← α_w[r]·exp(η); normalize α_w # 4b. exponentiated-gradient affinity update # losers do NOT update — that is what makes the assignment converge

The only "knobs" are λ (how generalist-averse the competition is) and η (how fast affinity sharpens). There is no gate to train, no router, no diversity loss, no labels. Code: NichePopulation.run_iteration + NicheAgent.update in src/agents/niche_population.py.

Math Exponentiated Gradient (Hedge / multiplicative weights) ›

The affinity update is the exponentiated-gradient (EG) rule — also known as Hedge, multiplicative weights, or mirror descent on the simplex with an entropic regularizer. For a binary win signal r_j = 1[j = winning regime]:

α_j ← α_j · exp(η·r_j) / Z , Z = Σ_k α_k·exp(η·r_k) # only the winning regime has r_j = 1, so in practice: α_win ← α_win · e^η # multiply winner α_j ← α_j # others unchanged (·e⁰ = 1) α ← α / Σα # renormalize back onto the simplex

Why this rule and not addition?

  • Simplex-preserving by construction. exp is always positive and we divide by a positive sum, so α stays a valid probability vector forever — no clamping, no "negative affinity" hacks. (The legacy V3 update added/subtracted and needed a max(0.01,·) clamp; that is kept only for comparison.)
  • It is mirror descent. EG is gradient descent in the dual (log) space — the Bregman/KL geometry of the probability simplex — which is the correct geometry for updating a distribution.
  • It is replicator dynamics. In the small-η limit, EG is exactly the discrete-time replicator equation from evolutionary game theory: α̇_j ∝ α_j·(f_j − f̄). That is the formal bridge to the "ecological niche" framing — affinities evolve like population shares under selection.
The repo rescales η by (R²−R+1)/(R−1) so EG matches the V3 specialization timescale (eg_eta_for_regimes). The sandbox exposes the effective η directly so you can see the dynamics move.
RL Thompson sampling & the Beta–Bernoulli bandit ›

Each learner's choice of method within a regime is a multi-armed bandit problem: arms = methods, reward = did this method work here. GAUSE solves it with Thompson sampling (posterior sampling):

B[r][m] = Beta(a, b) # posterior over P(method m succeeds in regime r) sample sₘ ~ Beta(a, b) ∀m # draw one optimistic sample per arm play m* = argmaxₘ sₘ # act greedily on the samples update on success: a ← a + 1 # Beta is conjugate to Bernoulli on failure: b ← b + 1
  • Exploration–exploitation is automatic: wide posteriors (few data) produce high-variance samples that occasionally win, so under-tried methods still get probed; as a+b grows the posterior concentrates and the best arm dominates. An extra ε-greedy term (ε starts 0.30, decays ×0.999, floor 0.05) adds early random exploration.
  • Conjugacy makes the Bayesian update a one-line increment — no gradients, no replay buffer.
  • In GAUSE the winner is always reinforced with success (the winner's reward = 1 by construction), so beliefs sharpen toward whatever methods keep winning the competition — coupling the bandit to the population dynamics.
RL Competitive exclusion, winner-take-all & reward-independence ›

These three ideas are the conceptual core — the reason GAUSE retains where standard RL allocators forget.

  • Competitive exclusion (Gause, 1934). Two species competing for the identical niche cannot coexist — one is excluded. GAUSE operationalizes this with the generalist-averse bonus: trying to win a regime that another learner already "owns" is penalised, so the population is pushed to partition the regime space. The name honors G. F. Gause.
  • Winner-take-all. Only the single highest-adjusted-reward learner updates; losers are frozen this step. This is what lets affinities converge to a stable assignment instead of all drifting together — it is a selection operator, not a gradient on a shared loss.
  • Reward-independence — the thesis. A converged specialist's capacity assignment no longer depends on current task reward: it owns its niche structurally. Contrast the failure modes:
    reward-chasing → forgets
    a capacity-bounded monolith, or a learned MoE gate, allocates to whatever pays reward now. A dormant regime emits no reward gradient → no signal to reserve capacity for it → it is overwritten.
    reward-independent → retains
    fixed random niches, an EOI/CDS diversity objective, or converged competition assign capacity regardless of current reward → dormant regimes survive. GAUSE is the most parsimonious of these.
This even corroborates MoE continual-learning theory (ICLR'25, arXiv:2406.16437): their result that the gate must be frozen for CL convergence is, in GAUSE's terms, making the assignment reward-independent — which competition reaches emergently.
Memory Bounded capacity: hard LRU vs. soft interference ›

"Memory" in GAUSE = each learner can master only K of R regimes. How forgetting happens depends on the model — and the headline dissociation holds under both, which is the point of testing two (it isn't an artifact of one eviction rule). Code: experiments/exp_nonstationary_capacity.py.

hard · LRU eviction (default)
A K-slot store. Learning a (K+1)-th regime evicts the least-recently-used one outright (store.popitem(last=False)). Dormant → not refreshed → falls to the back → evicted → must relearn from the prior on reactivation. Discrete, all-or-nothing forgetting.
soft · interference decay
No eviction. Once the learned footprint exceeds K, every update bleeds pseudo-counts out of the other held regimes toward the Beta(1,1) prior, ∝ overflow. Dormant regimes decay continuously — the interference account of catastrophic forgetting.
# soft interference (per learning update, when footprint > K): overflow = max(0, footprint − K) keep = 1 − 0.04 · overflow / footprint ∀ held regime r ≠ current: a ← 1 + (a−1)·keep , b ← 1 + (b−1)·keep

A GAUSE specialist sidesteps both: it only ever holds its one niche, so its footprint never exceeds K and dormancy never touches it. The monolith must hold every active regime alone, so it is permanently over capacity — that is the retention gap you see in the sandbox.

Math Information theory: entropy, SI, MSI, coverage & KL ›

Shannon entropy measures how spread-out a distribution is — high when uniform, zero when concentrated on one outcome. Normalized entropy divides by its max so it lands in [0,1]. Specialization = 1 − normalized entropy. The Deep Dive defines two distinct indices — one over regimes, one over methods:

H(p) = −Σ pₓ·log pₓ # Shannon entropy H̄ = H / log(support) # normalized entropy ∈ [0,1] SI = 1 − H(α) / log R # regime specialization — over niche affinity α MSI = 1 − H(π) / log M # method specialization — over method usage π both: 0 = generalist (uniform) … 1 = perfect specialist (one-hot)
Read this carefully — it is a subtle repo detail the sandbox now gets right. SI measures which regimes a learner owns (the bars in Part 2); MSI measures which methods it favours. The published headline "mean SI ≈ 0.65 at λ=0" is computed on method usage in src/analysis/specialization.py — i.e. what the Deep Dive formalizes as MSI. The sandbox plots both lines so you can see them diverge.
  • Effective regime count k_eff = exp(H(π_regime)). If one regime dominates (k_eff → 1) there is nothing to specialize between and SI collapses — the "mono-regime collapse" proposition. (Weather, k_eff ≈ 1.8, shows lower SI for exactly this reason.)
  • Coverage = how many distinct regimes are some learner's primary niche. A separate axis from SI: you want both high SI (each learner sharp) and full coverage (no regime orphaned). Competition, diversity, and the router all achieve coverage — it is a commodity; retention is where they split.
  • KL divergence D(P‖Q) = Σ P·log(P/Q) — asymmetric "distance" between distributions; used to compare a learner's affinity to uniform or to other learners.
RL Bayesian inference: Bayes, the Beta distribution & conjugacy ›

The bandit beliefs above are Bayesian posteriors. The machinery:

Bayes: P(θ|data) ∝ P(data|θ)·P(θ) # posterior ∝ likelihood × prior Beta(a,b): mean = a/(a+b) # belief that a method succeeds variance ↓ as a+b grows # more data ⇒ tighter, more confident Beta(1,1) = uniform prior # "no idea yet" Conjugacy (Beta–Bernoulli): prior Beta(a,b) + success → Beta(a+1, b) prior Beta(a,b) + failure → Beta(a, b+1)
  • Conjugacy = the posterior stays in the same family as the prior, so the Bayesian update is a one-line counter increment — no integration, no gradients. This is what makes Thompson sampling cheap.
  • A learner's belief about method m in regime r is a separate Beta(a,b); early on it is wide (explores), and concentrates as evidence accrues (exploits). The a+b sum is effectively a per-(regime,method) confidence counter — and the thing the memory models decay or evict.
RL Game theory: Nash, winner-take-all & the pigeonhole argument ›
  • Nash equilibrium — a strategy profile where no learner can improve by unilaterally deviating. GAUSE's converged partition (one specialist per niche) is such an equilibrium: given everyone else's niches, your best response is to own an under-contested one.
  • Winner-take-all (WTA) game — each round a single value V goes entirely to the top performer; everyone else gets 0. Rewards are never divided — there is always exactly one winner — but your probability of being that winner falls as a niche gets crowded.
  • Pigeonhole principle — with N learners and R regimes and N > R, at least one regime is contested by ⌈N/R⌉ learners. That guaranteed crowding is the pressure that pushes someone to deviate to an emptier niche.
  • Competitive exclusion (Gause, 1934) — two species in the identical niche cannot coexist; one is excluded. Darwin's finches evolved different beaks from competition, not coordination. GAUSE imports this: competition alone differentiates the population.
Math Why competition alone specializes (λ = 0) & the feedback loop ›

The supporting claim: specialization emerges even with the niche bonus off (λ = 0). The score is then just raw reward + noise — no niche advantage. Yet learners still diverge, via a four-step positive feedback loop:

specialize in r → higher affinity α_r → (with λ>0) higher niche bonus ↑ │ only winner updates ← more likely to win in r ←────────┘
  • 1 · random divergence — all learners start uniform; early winners are decided by noise, so by chance different learners rack up wins in different regimes.
  • 2 · winner-take-all path dependence — because only the winner updates, those random early wins compound into stable affinity gaps (e.g. after 50 steps a learner sits at 0.36 on its niche vs 0.21 elsewhere).
  • 3 · method learning reinforces — a learner that keeps winning regime r learns r's good methods (its Beta beliefs sharpen), giving it a real skill edge there — independent of any bonus.
  • 4 · crowding sustains it — in a niche crowded by k similar learners, each wins ≈ 1/k of the time, so expected payoff ≈ V/k. Deviating to an empty niche raises your expected wins. Crowding is self-correcting.

λ > 0 doesn't create specialization — it accelerates and sharpens a partition that competition already produces.

Sandbox caveat: this minimal in-browser port only weakly reproduces the λ=0 case — with binary rewards and pure argmax tie-breaking, learners herd rather than cleanly partition, so MSI stays near 0 at λ=0. Set λ > 0 to see the crisp partition. The full paper recovers the λ=0 result via the crowding / expected-payoff dynamics above.
Memory Mixture-of-Experts: the gate, and why a reward-driven router forgets ›

The strongest baseline. An MoE has experts f₁…f_N and a gate g that routes each regime to an expert (top-1 / hard routing here). The gate is a softmax over learned logits, trained to route toward whoever performs well now:

route: e_t = argmax_e gate[r_t][e] # (ε-greedy) grade: q = expert e_t's quality on r_t ∈ [0,1] update: gate[r_t][e_t] += η_g·(q − ½) # REWARD-following — the crux

Why it forgets a dormant regime — walk one through dormancy:

  • During dormancy regime r never fires, so no quality q_r is observed → Δgate[r] = 0 → the gate for r is frozen. It gets no signal that would make it reserve an idle expert for r.
  • Meanwhile the expert that owned r is the best available, so it keeps getting routed for the active regimes and — capacity-bounded — evicts its beliefs about r.
  • On reactivation the frozen gate dutifully routes r back to that expert — which has forgotten it. The router did everything right by its own objective and still forgot. The failure is structural, not a tuning bug.
A gate augmented with a memory-preservation or load-balancing term (a reward-independent pressure) could reserve capacity for dormant regimes — at the cost of the reward-following simplicity that defines a vanilla router. GAUSE gets that reward-independence for free from competition. Sandbox/paper: MoE post-reactivation 0.928 vs GAUSE 0.283 at K=1 (p ~ 10⁻³⁵).
Memory Continual learning & catastrophic forgetting — where GAUSE sits ›

The dormancy experiment is a continual-learning (CL) problem; the monolith's failure is catastrophic forgetting — train on task A, then on B, and A's accuracy craters because B's updates overwrote the shared weights that encoded A. A regime going dormant then reactivating is exactly the "re-test task A later" step.

Every CL method resolves the stability–plasticity dilemma: learn the new (plastic) without destroying the old (stable). The three standard families, and where GAUSE lands:

1 · Regularization (EWC)
anchor parameters important to old tasks. Soft protection; needs a per-parameter importance estimate. On real gas data its anchor fights drift → worse than naive.
2 · Replay / rehearsal
store old-task samples and interleave them. Needs memory of the data + continual replay.
3 · Architectural isolation
give different tasks different parameters (experts / masks) so new learning physically cannot overwrite old. ← GAUSE lives here
no protection
one shared box for everything → forgets. ← the monolith and the MoE router

GAUSE is parameter-isolation, but an unusual one: where standard isolation assigns experts by an external controller or task label, GAUSE lets the regime→agent assignment emerge from competition — no labels, no controller. The converged assignment is reward-independent, so each specialist idles through dormancy without updating, hence without forgetting.

Math Theoretical results — the propositions ›

The thesis is not just empirical; it is a proposition with a proof. The core objects:

  • Assignment-only class 𝒜 — mechanisms whose only protection of a dormant regime is the assignment itself (no rehearsal, no load-balancing acting during dormancy). The monolith, fixed random niches, EOI/CDS diversity, and competition are all in 𝒜.
  • Reward-driven assignment: its update for r depends only on quality signals observed while r is active. Reward-independent: it does not depend on current reward for r.
Proposition (Reward-Independence ⇒ Retention). Within 𝒜, for a long-enough dormancy window, retaining a dormant regime r REQUIRES the assignment for r to be (i) reward-independent and (ii) covering. Hence any reward-driven allocator in 𝒜 — the capacity-bounded monolith, the learned MoE router — FORGETS every regime that goes dormant.

Proof sketch (the "no-signal lemma"). While r is dormant, the active regime is always some r′ ≠ r, so a reward-driven rule observes no q_r and Δ-assignment[r] = 0 — the assignment is frozen on the expert e★ that owned r. But e★ stays in active use, so the memory model erodes its beliefs about r: hard LRU evicts once ≥K other regimes are served; soft interference decays r's pseudo-counts by κ<1 per update → 0. At reactivation the frozen assignment routes r back to the now-amnesiac e★. ∎

Companion results: mono-regime collapse (as one regime dominates, k_eff → 1 and SI → 0 — nothing to specialize between), and a reallocation-rate proposition replacing the earlier hand-wave necessity claim.

What a "method" concretely is. A method maps recent history → a prediction/action. Each domain ships M = 5: e.g. naive/persistence (ŷ = last value), moving average, momentum, mean-reversion, trend-following (MA crossover). A regime has an affinity matrix A(r,m) saying which methods pay off in it — that is the latent structure GAUSE's learners discover via their Beta beliefs. RL Glossary — quick reference ›
regime
a distinct environment condition with its own best method; the unit GAUSE specializes to. Non-stationary: active → dormant → reactivate.
niche affinity α
a learner's distribution over regimes — which it "belongs" to. EG-updated. Lives on the simplex Δᴿ.
method
a concrete prediction strategy a learner can play within a regime (the bandit arms).
catastrophic forgetting
a learner overwrites old-task knowledge while learning a new one — the continual-learning failure GAUSE addresses by structural retention.
MoE router / gate
a learned module that assigns inputs to experts. Reward-chasing → forgets dormant regimes (no gradient to protect them).
EOI / CDS
intrinsic-diversity objectives (explicit identity reward). Reward-independent → retain, but need an extra objective to tune; competition gets there for free.
replicator dynamics
evolutionary-game equation for how strategy shares evolve under selection; the small-η limit of EG, bridging to the ecological framing.
λ (niche bonus)
strength of the generalist-averse competition. λ > 0 makes partitioning crisp here; the "competition-alone" λ=0 result (published MSI≈0.65) is a subtler crowding effect this minimal sandbox only weakly reproduces.
